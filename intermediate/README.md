# Intermediate data

`intermediate/prepared_stock/` contains stable building-to-component and spatial mappings used by several figures. `intermediate/spatial/` contains prepared boundaries and simplified roads used for map rendering. `intermediate/city_trajectories/` contains an accepted 15-minute city trajectory used for the 2009 peak-definition diagnostic.

These files are machine-readable products between primary data preparation/simulation and the final analysis tables. They are included because they are needed by the executable notebook and are substantially smaller than the original simulator output hierarchy.
