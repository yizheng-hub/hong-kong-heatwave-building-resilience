# Plotting notebook

`plot.ipynb` contains 23 executable plotting cells in publication order: Figure 1 through Figure 6, followed by Supplementary Figure S1 through Supplementary Figure S17. Each cell contains its own imports, file reads, calculations and styling. It does not delegate figure construction to an external plotting script.

Running the notebook from either the repository root or this directory writes PNG files to `output/figures/`. The supported automated entry point is `python src/run_pipeline.py`.
