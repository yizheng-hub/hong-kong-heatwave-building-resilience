# HK-BFETD input

Expected provider file: `HK_UBEM_Buildings_Public_v1_1.csv`.

Obtain the published building-stock input from the [HK-BFETD Zenodo record](https://zenodo.org/records/20710499) and retain the provider filename in this directory. The repository does not relicense or repackage the file because the record identifies copyright but does not state a reusable data licence.

This file is an original study input. Filtered stock mappings derived from it are stored under `intermediate/prepared_stock/`.
