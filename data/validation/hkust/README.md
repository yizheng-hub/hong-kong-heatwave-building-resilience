# HKUST campus input

The original 2.5-year campus smart-meter dataset is available from Dryad: <https://doi.org/10.5061/dryad.k3j9kd5h6>.

Expected provider archive: `All_Data.zip` (approximately 1.43 GB). Dryad distributes the dataset under CC0. The archive is not duplicated in this Git repository because of its size; the compact comparison results used by the paper are under `result/validation/`.
