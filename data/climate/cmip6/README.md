# CMIP6 inputs

This directory is reserved for original or provider-extracted CMIP6/ScenarioMIP series used for the five-model climate background. Obtain source data through the [ESGF CMIP6 project](https://esgf-node.llnl.gov/projects/cmip6/) and retain model, experiment, member, variable and calendar identity.

Bias-corrected fields, ensemble summaries and figure panel tables are outputs and belong under `intermediate/` or `result/`.
