# Hong Kong Observatory inputs

This directory is reserved for original HKO API responses and downloaded station records. Obtain them from the [HKO Open Data service](https://www.hko.gov.hk/en/abouthko/opendata_intro.htm).

Redistribution and reuse must follow the HKO intellectual-property notice, conditions of use and required acknowledgement. No HKO response is repackaged in this repository. Corrected weather fields, station summaries and heatwave catalogue tables belong under `intermediate/` or `result/`, not here.
